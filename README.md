## 一个常见误区：IP 被封后能不能切换机房换 IP

这个思路听起来很聪明——反正切机房也会换 IP，又是免费的，直接切不就行了？

行不通。官方政策是：一旦检测到 VPS 的 IP 在大陆被完全屏蔽，KiwiVM 后台的机房迁移功能会被自动禁用。你去点 "Migrate to another DC" 会反复看到错误代码，根本提交不了。

所以不是操作哪里不对，是官方压根不让你走这条路。

IP 没被封的时候，切机房换 IP 是完全可以的，算免费操作。但 IP 一旦进了黑名单，只能老老实实走 $8.79 的付费流程。
